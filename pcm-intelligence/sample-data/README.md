# Arquivos inteiramente fictícios

Os CSV abaixo demonstram o contrato genérico de importação. Não representam layouts reais SAP ou SKA. No módulo Importações, também é possível baixar exemplos CSV e XLSX de cada tipo.

1. Crie uma origem de **dados fictícios** para cada tipo.
2. Use a mesma identificação de base entre relatórios correspondentes.
3. Importe equipamentos primeiro, ou autorize referências ausentes.
4. Importe `ordens-dia-1-ficticio.csv` e depois `ordens-dia-2-ficticio.csv`: uma OS é atualizada, uma permanece igual e outra é criada.
5. Mapeie os cabeçalhos, tipos, status e prioridades na prévia. Os códigos usados nos exemplos coincidem com as escolhas internas apenas para facilitar o teste.
6. Planos exigem responsável: selecione criação de referências ou cadastre o técnico fictício antes.

Não envie informações reais da empresa ao repositório.
